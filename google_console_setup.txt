================================================================
  FRAME STUDIO -- GOOGLE CLOUD CONSOLE SETUP (one-time, ~5 min)
================================================================

Frame Studio uses "Sign in with Google" as its login, and the SAME
sign-in also authorizes saving frames to your Google Drive. To make
this work you (the app owner) must register the app once in Google
Cloud Console and paste four values into the .env file.

Follow the steps below in order.


----------------------------------------------------------------
  STEP 1 -- Create a Google Cloud project
----------------------------------------------------------------

  1. Open https://console.cloud.google.com/projectcreate
  2. Project name: Frame Studio  (any name works)
  3. Click CREATE
  4. Wait a few seconds, then make sure the new project is selected
     in the project picker at the top of the page.


----------------------------------------------------------------
  STEP 2 -- Enable the required APIs
----------------------------------------------------------------

  In the left sidebar:
    APIs & Services  ->  Library

  Search for and enable:

    [x] Google Drive API

  (Click ENABLE. No other APIs are required.)


----------------------------------------------------------------
  STEP 3 -- Configure the OAuth consent screen
----------------------------------------------------------------

  APIs & Services  ->  OAuth consent screen

  User type:
    -  External    (choose this if you're using a personal Gmail)
    -  Internal    (only if you're on a Google Workspace org)

  App information:
    App name:               Frame Studio
    User support email:     (your email)
    Developer contact:      (your email)

  Click SAVE AND CONTINUE.

  Scopes  ->  ADD OR REMOVE SCOPES  ->  add ALL of these:

    openid
    .../auth/userinfo.email
    .../auth/userinfo.profile
    https://www.googleapis.com/auth/drive.file
    https://www.googleapis.com/auth/drive.readonly

  Click UPDATE, then SAVE AND CONTINUE.

  Test users  ->  + ADD USERS:
    Add the Gmail address you'll use to sign in. While the app is
    in "Testing" mode, ONLY accounts on this list can log in.

  Click SAVE AND CONTINUE  ->  BACK TO DASHBOARD.


----------------------------------------------------------------
  STEP 4 -- Create the OAuth client ID
----------------------------------------------------------------

  APIs & Services  ->  Credentials
  Click  + CREATE CREDENTIALS  ->  OAuth client ID

  Application type:        Web application
  Name:                    Frame Studio Web Client

  Authorized JavaScript origins:
    http://localhost:3000

  Authorized redirect URIs:
    http://localhost:3000/auth/google/callback

  Click CREATE.

  A dialog appears with TWO values -- COPY BOTH:
    Client ID       ->  goes into GOOGLE_CLIENT_ID
    Client secret   ->  goes into GOOGLE_CLIENT_SECRET


----------------------------------------------------------------
  STEP 5 -- Paste the values into .env
----------------------------------------------------------------

  Open the .env file at the project root and fill in:

      APP_URL=http://localhost:3000
      GOOGLE_CLIENT_ID=<step 4 client id>
      GOOGLE_CLIENT_SECRET=<step 4 client secret>

  (GOOGLE_API_KEY and GOOGLE_APP_ID are no longer needed --
  Frame Studio uses its own in-app folder explorer instead of
  Google Picker.)


----------------------------------------------------------------
  STEP 6 -- Restart and test
----------------------------------------------------------------

  Stop the dev server if it's running, then:

      npm run dev

  Open http://localhost:3000 -- you should land on the login page
  with a "Continue with Google" button (no more warning banner).

  Sign in.  Upload a video.  Extract frames.  Select a few.
  Click "Save to Drive" -- our in-app folder explorer opens. Browse
  to a folder (or click "Create folder" to make a new one), then
  "Save here".  The images land in your Drive.  Done!


================================================================
  TROUBLESHOOTING
================================================================

"access_denied" right after Google sign-in
  -  The consent screen is in Testing mode.  Add the Gmail
     address you're using under OAuth consent screen -> Test users.

"redirect_uri_mismatch"
  -  The Authorized redirect URI in step 4 must match EXACTLY:
       http://localhost:3000/auth/google/callback
     (no trailing slash, no https, no different port)

Folder explorer / Drive video picker says "Insufficient Permission"
  -  You signed in with the old scope set. Sign out of Frame
     Studio and sign in again to grant the new drive.readonly
     scope (used for listing folders AND downloading the video
     you import).

"Login Required" or 401 when saving to Drive
  -  Sign out of Frame Studio and sign in again. This mints a
     fresh refresh token.

"Sign in with Google isn't configured yet" still shows on /login
  -  Did you restart the server after editing .env? Node only
     reads .env at startup.
